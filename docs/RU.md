# FujiRelay

Передаёт JPEG с Fujifilm X-T30 II в твой Immich через небольшой кэш на Android.
Не нужно сначала скачивать всю SD-карту на телефон.

## Как пользоваться

1. В камере выбери **USB CARD READER**, отключи **USB POWER SUPPLY**.
2. Подключи камеру кабелем USB-C для данных. Закрой другие импортёры и разреши USB-доступ.
3. В настройках FujiRelay введи адрес Immich и API-ключ с правами
   `asset.upload`, `asset.read`, `user.read`.
4. Начни с кнопки **⋮ → Передать один кадр**. Проверь фотографию в Immich.
5. Затем нажми **Передать фотографии**.

По умолчанию приложение хранит максимум **100 фото или 1 ГиБ**, что наступит
раньше. Перед новым файлом оно также проверяет, что останется **512 МиБ** свободного
места. Лимиты количества и размера можно изменить в настройках.

Кадры скачиваются партиями. Во время отправки каждый JPEG удаляется из кэша
сразу после проверки в Immich и записи подтверждения в SQLite. Следующая партия
скачивается после освобождения места.

## Выбор и остановка

На главном экране доступны **Сегодня**, **Вчера** и **Период**. Конечная дата
включена в диапазон. Границы суток определяются часовым поясом телефона,
время съёмки берётся из каталога камеры.

**Выбрать кадры** открывает сетку фотографий. Можно отметить отдельные файлы
или выбрать весь день. Выбор сохраняется после перезапуска и распространяется
также на файлы, которые уже находятся в кэше.

**Пауза** завершает текущую операцию. **Остановить передачу** прерывает сетевой
запрос и прекращает USB-чтение между блоками по 256 КиБ. Завершённые кадры без
подтверждения Immich остаются в очереди; временная незавершённая копия удаляется.
Остановку можно вызвать и из уведомления.

Превью ограничены 100 кадрами и 8 МиБ. Остальные кадры доступны для выбора
по имени и времени; обновление каталога получает превью для текущего фильтра.

## Когда можно удалить локальную копию

Одного имени файла или ответа «HTTP 200» недостаточно. FujiRelay получает ID
фотографии в Immich, запрашивает её сведения и проверяет совпадение SHA-1,
владельца и отсутствие признаков корзины/недоступности. Только затем записывает
подтверждение в БД и удаляет свой файл.

Генерацию превью и распознавание лиц ждать не нужно. Подтверждение опирается
на API сервера; повторное скачивание оригинала для независимой проверки пока
не реализовано.

Если сеть оборвалась, сервер вернул ошибку или контрольная сумма не совпала,
JPEG остаётся в кэше. Новые кадры сверх лимита не скачиваются. Позже нажми
**Продолжить** — камера для этого не нужна. Либо снова запусти
полную передачу: сначала уйдут оставшиеся файлы.

База помнит доставленные кадры после очистки кэша и обновления APK. История
разделена по серверу и аккаунту Immich. Удаление приложения или очистка его данных
удаляет и историю, и неотправленный кэш.

## Текущая готовность

USB-передача проверена на X-T30 II и Pixel 7 Pro. Ошибки протокола, ограничения
кэша и восстановление проверяются на телефоне с тестовым сервером. Настоящий
Immich ещё предстоит подключить после обновления сервера.

Встроенное приложение Immich для этой очереди не требуется. FujiRelay хранит
свой кэш отдельно от галереи, а ключ — в зашифрованном виде с Android Keystore.
Для HTTP нужен отдельный переключатель; предпочтителен HTTPS.
